# IntroToGitHub

## What Is Version Control?

Version control is a system that tracks changes to files over time. It allows developers to review previous versions, restore earlier work, and collaborate on projects without losing track of changes.

## SSH Authentication

I configured SSH authentication to connect my local Git repository to GitHub. SSH allows me to authenticate using a public and private key pair instead of relying on an HTTPS remote URL.

## Basic Git Commands

These are some common Git commands that are useful when working with version control.

| Command | Purpose |
|---|---|
| `git init` | Creates a new local Git repository. |
| `git add` | Stages changes for a commit. |
| `git commit` | Saves staged changes to local history. |
| `git push` | Uploads commits to GitHub. |
| `git pull` | Retrieves and integrates remote changes. |
| `git branch` | Lists or creates branches. |
| `git merge` | Combines changes from another branch. |
| `git stash` | Temporarily saves uncommitted changes. |
| `git checkout` | Switches branches or restores files. |
