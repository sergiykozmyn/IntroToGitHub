# IntroToGitHub

## What Is Version Control?

Version control is a system that tracks changes to files over time. It allows developers to review previous versions, restore earlier work, and collaborate on projects without losing track of changes.

## What I Learned

This repository is part of my CSCI 1000 assignment at the University of Colorado Boulder. I am using it to practice basic Git commands, including initializing a repository, staging files, committing changes, and pushing my work to GitHub.

## SSH Authentication

I configured SSH authentication to connect my local Git repository to GitHub. SSH allows me to authenticate using a public and private key pair instead of relying on an HTTPS remote URL.
